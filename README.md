# QLock

Windows 上的一个锁屏小工具。锁定之后桌面变成一张模糊的截图，中间是时钟和密码框，输对密码就回桌面。
密码是 QLock 自己的，和 Windows 账户没有关系，所以不会把 Windows 账户锁住、也不用记两个密码。

这是 0.3.0 的 WPF 实现，已经不再加新功能，只留作参考和回头修 bug。它的检查更新读的还是主项目仓库的 Releases，主项目发新版后别用它自动升级。主项目是 [haha0614/QLock](https://github.com/haha0614/QLock)，用 C++ 重写，版本号从 0.1.0 重新起算。

版本 0.3.0，MIT 协议，未签名。

## 安装

1. 从 [主项目的 v0.3.0 Release](https://github.com/haha0614/QLock/releases/tag/v0.3.0) 下载 `QLock.exe`，放到一个以后不会随手清掉的目录。开机自启记的就是这个路径。
2. 双击运行。第一次没有密码，会自动弹出设置窗，设一个至少 4 位的密码，保存。
3. 想开机自启，在设置里勾上「登录时自动启动」再保存。只写当前用户的启动项，不用管理员。

如果既勾了「登录时自动启动」，又勾了「程序启动后立即锁定」，那就别再勾「以管理员身份启动」。
开机自启提权会先弹一个 UAC 确认框等人点，这期间锁屏还没起来，桌面是露着的，等于没锁。
要提权就手动右键以管理员身份运行，别让它跟着登录一起走。

不放心可以先校验：`Get-FileHash QLock.exe -Algorithm SHA256`，和 `SHA256SUMS.txt` 对一下。

程序每天第一次启动时会去 Releases 看一眼有没有新版本，有的话弹一个窗口写清楚更新了什么，
你点「下载并升级」才会下载，校验过 SHA256 之后原地替换 exe 并自己重启，配置和密码都保留。
不想再被这个版本提醒就点「跳过这个版本」。设置窗最下面也能手动查。
下载的文件放在 `%TEMP%\QLock-update`，替换前的旧 exe 会临时改名成 `QLock.exe.old`，下次启动时删掉。

系统要求：Windows 10 1903 或更高、Windows 11，自带 .NET Framework 4.8 就能跑。

## 锁定与解锁

锁定有这几种方式：

- 双击托盘图标，或者右键选「立即锁定」
- 命令行 `QLock.exe --lock`
- Win+L，默认接管
- Ctrl+Alt+L，可以在设置里关掉
- 空闲一段时间自动锁，设置里填分钟数，0 是关闭
- 程序一启动就锁，默认关

解锁就是输密码、回车。忘了密码点「忘记密码？用恢复码解锁」，填设置时生成的那串恢复码。
恢复码只显示一次，用掉就作废，想继续用作废后重新生成。
连续输错 3 次会暂停输入几秒，之后每错一次多停一秒，最多 10 秒。

## 设置里有什么

左边一列导航，右边是这一页的设置项，一页就能看完，不用滚。

| 分区 | 内容 |
| --- | --- |
| 解锁方式 | 当前密码（眼睛按钮看明文）、改密码、生成新的恢复码（只显示一次，同时复制到剪贴板） |
| 外观 | 锁屏预览、锁屏主题、背景图片、显示时钟和日期、提示文字（可整行关掉）、截图背景（默认关）、圆角、模糊度、遮罩透明度、界面字体、时钟字体 |
| 启动与锁定 | 接管 Win+L、Ctrl+Alt+L、启动即锁、空闲 N 分钟、登录时自动启动、以管理员身份启动 |
| 加固 | 拦截系统热键 |
| 关于 | 当前版本、检查更新、配置和日志的位置 |

改完就生效，没有「保存」按钮：开关一拨就写进配置文件；密码要按旁边的「设置」才改。
外观页顶上那块预览固定在顶部，不跟着下面的设置项滚，改字体也看得见；换主题、换背景图、拖滑块、关时钟、开截图背景、改提示文字都会当场跟着变。

「背景图片」挑一张本地图片当锁屏背景，挑了就优先于截图背景；点「恢复纯色」回到主题自己的底色。下面的圆角、模糊度、遮罩透明度三个滑块默认跟着主题走，拖过之后就固定成你拖的值，换主题也不会被改回去。注意这几项对锁屏上的卡片、输入框、按钮同时生效，所以任何主题下都看得见。

勾了「用屏幕截图做模糊背景」又没挑背景图时，预览拿你当前的桌面壁纸顶替——真锁屏截的是锁那一刻的屏幕，预览只能是壁纸。

字体也是在这一页换：界面字体管设置窗和锁屏上的所有文字，从系统里装的字体中挑；时钟字体那行有个开关，打开之后时钟单独用另一种字体，其余文字还是界面字体。
「以管理员身份启动」和「登录时自动启动 + 程序启动后立即锁定」一起用会在登录时露桌面，见上面「安装」。

## 锁屏长什么样

内置三套主题，在设置 → 外观里切换，改完下一次锁屏就换过去：

- Windows 11 Fluent（默认）：时钟置上，下面是输入框和蓝色按钮，没有卡片
- 卡片：中间一张半透明卡片，带 Q L O C K 字标
- 极简：纯黑底，一条下划线输入框，「解锁」是文字按钮

想自己改，点设置里的「主题文件夹」，里面是三套主题的 JSON。文件名随意，程序看文件里的 Id。
内容按时钟、日期、卡片、字标、提示文字、输入框、按钮、链接、背景分块，颜色写 #AARRGGBB，尺寸是像素。
单个文件最大 64 KB，最多读 40 个；解析不了的文件会被跳过、在日志里留一行，锁屏照常用内置主题。
自己写的主题只要 Id 和内置的那套撞了，就会盖掉内置的。

## 命令行

| 参数 | 作用 |
| --- | --- |
| 无 | 常驻托盘 |
| `--lock` | 立刻锁定，已经有实例在跑就把指令转过去 |
| `--settings` | 打开设置窗 |
| `--demo` | 演示锁屏 10 秒后退出，不需要密码 |
| `--check-update` | 立刻检查一次更新，不看「每天一次」的限制 |

## 文件在哪

- 配置：`%APPDATA%\QLock\config.json`。密码校验用的是 PBKDF2 的 hash；另存一份用 Windows DPAPI 加密的拷贝，只给设置页回显，换账户或换机器都解不开。
- 日志：`%LOCALAPPDATA%\QLock\qlock.log`，超过 512 KB 自动重建
- 主题：`%APPDATA%\QLock\themes`，第一次启动时生成三套样例
- 更新下载：`%TEMP%\QLock-update`，装完就删

## 卸载

1. 托盘右键退出。先退出再删文件。
2. 设置里关掉「登录时自动启动」（关掉就生效）。忘了也没关系，手动删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `QLock` 值。
3. 删掉程序目录，以及 `%APPDATA%\QLock`、`%LOCALAPPDATA%\QLock`。

## 还要改 Windows 的几个设置

QLock 只管自己那层锁屏。系统的锁屏一旦触发，出现的仍然是 Windows 登录界面。想让它别出现：

1. 设置 → 账户 → 登录选项 →「如果离开了电脑，Windows 何时要求你重新登录」→ 从不
2. 设置 → 个性化 → 锁屏界面 → 屏幕保护程序 → 无，或者取消「在恢复时显示登录屏幕」
3. 控制面板 → 电源选项 → 唤醒时需要密码 → 不需要密码，笔记本电池和电源两种状态都要改
4. 公司电脑如果被组策略下发了 `Machine inactivity limit` 之类的策略，客户端改不了，只能尽量别让机器休眠

## 能挡住什么，挡不住什么

锁屏期间键盘钩子会吞掉 Win 系列热键、Alt+Tab、Ctrl+Esc、Ctrl+Shift+Esc、Alt+F4。
覆盖层一旦丢掉前台会立刻抢回来，抢回来这段路上的按键全部丢掉，不会漏到后面的窗口里。

勾上「以管理员身份启动」之后，普通权限的任务管理器结束不了它。这个选项默认关，而且只在启动时生效，
Windows 不允许给已经跑起来的进程提权。不在管理员组的账号勾了也没用。

挡不住的是 Ctrl+Alt+Del。那是内核处理的，任何程序都收不到，从安全界面可以结束进程或者跑 taskkill 把它关掉。
所以这东西是用来挡顺手看一眼屏幕的，别当安全边界。

## 其他

- 只有主屏能操作，其它屏幕只显示背景和时钟
- 锁屏时插拔显示器、改分辨率会重建覆盖层，布局没变就只重新置顶一下
- 托盘常驻大约 33 MB，锁屏时 94 MB 左右，多出来的是每块屏一个全屏窗口加模糊的渲染目标，解锁后会压回去
- 远程控制软件抢前台时可能打字没反应，程序每次失去前台都会抢回来，实在抢不回来日志里会有一条 `input blocked`
- 未签名，SmartScreen 会提示"未知发布者"。程序会用键盘钩子、会写当前用户的启动项，但不碰任何策略注册表

## 自己编译

不需要 Visual Studio，也不需要 NuGet 或项目文件，直接用系统自带的 csc：

- `build.cmd` 编出 `bin\QLock.exe`
- `test.cmd` 编完跑 `tests\TestMain.cs` 里的断言
- `pack.cmd` 输出 `dist\QLock.exe` 和 `dist\SHA256SUMS.txt`

语言级别是 C# 5，用不了 `?.`、`nameof` 和字符串插值。

源码大致这样分：`Program.cs` 是外壳、单实例和命令行，`LockController.cs` 是状态机和键盘钩子，
`Updater.cs` 查 Release、校验并替换 exe，`UpdateWindow.cs` 是那个更新窗口，
`LockWindow.cs` 是每块屏一个的全屏窗口，`LockTheme.cs` 是主题的读入和内置三套，`Native.cs` 放 P/Invoke，`Auth.cs` 是 PBKDF2 和恢复码，
`AppConfig.cs` 是配置和原子写，`Design.cs` 是尺寸和字号的那套数值，`FontPicker.cs` 是选字体的窗口，
剩下 `Ui.cs`、`SettingsWindow.cs`、`TrayIcon.cs`、`Snapshot.cs`、`Log.cs`。

图标 `src\QLock.ico` 由 `tools\makeicon.ps1` 生成，用的是 QTools 那只兔子（Lucide rabbit，ISC）。
版本号只写在 `src\AssemblyInfo.cs` 里，推 v 开头的 tag 会触发 release.yml 发版。
